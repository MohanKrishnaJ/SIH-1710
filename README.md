## Problem Title
SIH 1710: Enhancing Navigation for Railway Station Facilities and Locations

### Problem Description

When users click a website link in WhatsApp Desktop, it opens in the default browser configured in Windows. Users may want to change this browser to Google Chrome, Microsoft Edge, Firefox, or another preferred browser.

### Solution

Change the default browser in Windows Settings so that links clicked in WhatsApp Desktop open in the preferred browser.

### Steps to Change the Default Browser

#### Step 1: Open Windows Settings

- Press `Windows + I` on your keyboard.
- The Windows Settings window will open.

#### Step 2: Open Default Apps

- Click **Apps** in the sidebar.
- Select **Default apps**.

#### Step 3: Select Your Preferred Browser

- Search for your preferred browser, such as Google Chrome, Microsoft Edge, or Firefox.
- Click the browser from the search results.

#### Step 4: Set the Browser as Default

- Click **Set default** if the option is available.
- If necessary, configure the browser as the default application for HTTP and HTTPS links.

#### Step 5: Test WhatsApp Desktop

- Open WhatsApp Desktop.
- Open a chat containing a website link.
- Click the link.
- The website should open in your selected default browser.

### Expected Result

Website links clicked in WhatsApp Desktop will open in the browser configured as the Windows default browser.

### Important Note

This change affects the default browser for Windows applications generally, not only WhatsApp Desktop. WhatsApp does not provide a separate setting for choosing the browser used to open links.

### Conclusion

Changing the default browser through Windows Settings is the standard way to control which browser opens website links from WhatsApp Desktop on a PC.
